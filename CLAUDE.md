GardenDesign — Планировщик сада

Продукт: сайт, где клиент задаёт размеры садового участка и размещает объекты ландшафтного дизайна.

Цель: создать простой сайт с 2D- и 3D-визуализацией сада.

Стек: Node.js + Express, HTML, CSS, JavaScript, Canvas для 2D и Three.js для 3D.

Функции:

1. Пользователь задаёт ширину и длину участка в метрах.
2. Выбирает объекты: деревья, цветы, кустарники, дорожки и беседки.
3. Размещает и перемещает объекты на 2D-плане.
4. Переключается между 2D-планом и 3D-садом.
5. Может удалять объекты и сохранять проект в браузере.

Дизайн: минималистичный, природные цвета — зелёный, бежевый и белый.

Ограничения: без базы данных, регистрации и платных сервисов. Не усложнять код.

Правила: работать поэтапно, проверять каждую функцию и фиксировать крупные изменения через Git.

План:

1. Создать интерфейс и 2D-планировщик.
2. Добавить 3D-сцену и переключение между режимами.
3. Добавить сохранение проекта и проверить работу сайта.
